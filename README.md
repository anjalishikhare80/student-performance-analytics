# Student Performance Analytics System

## Objective

The aim of this project is to analyze student marks and attendance using Python, NumPy and Pandas.

## Technologies Used

- Python
- NumPy
- Pandas

## Dataset

The dataset contains:

- Student ID
- Name
- Department
- Python
- Java
- DBMS
- Web Development
- Data Analytics
- Attendance

## Features

- Calculate total marks
- Calculate average marks
- Assign grades
- Pass/Fail result
- Rank students
- Subject analysis
- Top performers
- Attendance status

## Project Structure

student-performance-analytics/
│
├── main.py

## How to Run

Install libraries:

```bash
pip install pandas numpy
```

Run:

```bash
python main.py
```
